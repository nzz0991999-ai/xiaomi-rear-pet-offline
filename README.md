# 小米妙享背屏 · 赛博大眼睛桌宠（纯离线版）

免电脑、免 Root、无需任何 AI 工具，纯手机畅玩 **白 / 蓝 / 黄 / 绿 / 红 5 色赛博大眼睛桌宠**！

- **适配背屏机型**：小米 17 Pro / 17 Pro Max / 18 Pro / 18 Pro Max 等小米妙享背屏机型
- **通用全屏模式**：任意普通安卓手机 / 平板无需 Shizuku，点击底部绿色按钮即可纯黑全屏运行
- **自由切色 & 互动**：单指长按背屏 **2 秒** 呼出菜单随时切换 5 种颜色与微调挖孔/大小/亮度；单击大眼睛 Wink/互动，左右轻滑触发彩蛋
- **支持 App 内一键更新**：后续发新版后，打开 App 点右上角 **「检查更新」** 即可自动下载安装，无需每次重新找安装包（内置国内加速镜像兜底）

> 想把背屏联动电脑 AI 编程助手（Codex / Claude Code / DeepSeek Harness / Antigravity）？请前往原版仓库：[xiaomi-rear-ai-pet](https://github.com/nzz0991999-ai/xiaomi-rear-ai-pet)

## 更新日志

### v1.0.3（深度功耗优化 + 防主屏卡死硬熔断）
- **深度渲染省电（功耗显著下降）**：重构 Canvas 渲染管线，彻底移除高耗电 GPU `shadowBlur` 动态阴影改用轻量双层光晕；采用自适应帧率调度（待机 14 FPS / 互动 30 FPS / 瞌睡 5 FPS）并限制渲染像素比，让 LTPO 背屏自动降频，同时默认 OLED 亮度调优至 78%（可在背屏长按菜单自由调节）。
- **背屏熄屏零耗电 + 事件驱动守护**：监听背屏物理开关状态，背屏熄灭时立即暂停动画循环与后台轮询（0% GPU/CPU 占用）；背屏再次亮起瞬间毫秒级恢复，锁屏切回原主题照常自动拉回。
- **新增「背面贴桌自动黑屏休眠（省电推荐）」**：开启守护模式后，手机正面朝上平放桌面 6 秒自动纯黑休眠并释放背屏常亮锁，拿起或翻转手机立即唤醒并自动拉回大眼睛（无需解锁主屏，可在 App 首页随时开关）。
- **新增主屏防卡死硬熔断机制**：除主屏暂存期间禁止拦截触摸、主动退后台与强校验搬运外，新增 `onStop(d=0)` 生命周期硬熔断，物理杜绝背屏画面意外投到正面锁死屏幕。

### v1.0.2
- **修复锁屏后双击背屏停留在系统原主题问题**：开启「守护模式」后，即使正面手机处于锁屏状态，只要背屏切回小米原主题或再次唤醒背屏，都会在 ~0.2 秒内原位拉回大眼睛桌宠，**无需解锁主屏**。
- **新增 App 内一键检查更新**：右上角点「检查更新」或启动自动检测，支持 GitHub 直连与国内加速镜像自动兜底。
- **修复小米 17 Pro / 17 Pro Max 偶发投在正面卡住问题**：主屏暂存期间启用 `FLAG_NOT_TOUCHABLE` + 主动退后台 + 强校验主屏退后台后再搬运，彻底杜绝卡死正面桌面。

## 关于双击背屏息屏的说明
- 若你在「守护模式」下双击背屏导致系统跳回原主题，新版 `v1.0.2` 会自动拉回桌宠（锁屏状态也会自动拉回）；
- 若系统双击背屏触发了小米自带的「双击息屏」，再次亮起背屏时同样会自动切回桌宠，如需彻底关闭双击息屏可在手机系统「设置 → 息屏与锁屏」中关闭「双击亮屏与息屏」。
