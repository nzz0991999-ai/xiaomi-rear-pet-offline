# 小米妙享背屏 · 赛博大眼睛桌宠（纯离线版）

免电脑、免 Root、无需任何 AI 工具，纯手机畅玩 **白 / 蓝 / 黄 / 绿 / 红 5 色赛博大眼睛桌宠**！

- **适配背屏机型**：小米 17 Pro / 17 Pro Max / 18 Pro / 18 Pro Max 等小米妙享背屏机型
- **通用全屏模式**：任意普通安卓手机 / 平板无需 Shizuku，点击底部绿色按钮即可纯黑全屏运行
- **自由切色 & 互动**：单指长按背屏 **2 秒** 呼出菜单随时切换 5 种颜色与微调挖孔/大小/亮度；单击大眼睛 Wink/互动
- **支持 App 内一键更新**：后续发新版后，打开 App 点右上角 **「检查更新」** 即可自动下载安装，无需每次重新找安装包（内置国内加速镜像兜底）

> 想把背屏联动电脑 AI 编程助手（Codex / Claude Code / DeepSeek Harness / Antigravity）？请前往原版仓库：[xiaomi-rear-ai-pet](https://github.com/nzz0991999-ai/xiaomi-rear-ai-pet)

## 更新日志

### v1.0.11（彻底根除后台守护导致桌宠跳到主屏）
- **后台守护严格禁止触碰主屏（Display 0）**：移除 `guard_repin` 后台冷重建中把背屏任务移回主屏（`moveRoot(id, 0)`）以及后台 `am start --display 0` 的全部路径；自动守护仅在背屏原位拉回，从根源上杜绝待机/解锁时桌宠意外弹出到正面主屏；仅当用户主动点击「一键投到妙享背屏」或通知栏「立即拉回背屏」时才执行重新投射。

### v1.0.10（彻底修复贴桌休眠拿起后退回默认壁纸）
- **贴桌休眠不再释放守护占位**：开启守护模式后，正面朝上平放桌面 5 秒依然立即切换为 AMOLED 纯黑 `#000000` 并完全停掉 GPU 动画渲染与后台轮询，但不再释放背屏常亮占位锁，从根源杜绝 HyperOS 在平放期间把背屏踢回默认壁纸；拿起手机 0.2 秒内无缝亮回大眼睛，不再闪现原主题。
- **强化锁屏拉回时序**：`refront` 指令改为先唤醒背屏再置顶任务，即便手动双击息屏也能稳稳拉回。

### v1.0.9（底层自动对齐官方背屏正方向，通杀 90° 横倒与 180° 颠倒）
- **系统级自动方向对齐**：投屏前自动读取小米自带 `SubScreenLauncher` 在背屏上的基准旋转角；抵达背屏后自动比对当前窗口方向，只要存在 90° 或 180° 偏差，原生层立即精确锁定到官方正方向（同时前端按精确角度差兜底矫正与映射触摸坐标），界面零多余开关，全自动适配小米 17 Pro / 17 Pro Max 及 Android 16 / 17。

### v1.0.8（防解锁跳主屏双保险 + 撤回不闪现 + 280 字极简日志）
- **防解锁跳到主屏双保险**：背屏桌宠已投屏后，若系统在解锁时将其拉回主屏（`displayId == 0` 或窗口长边 `≥ 1600px`），立即退后台并自动销毁，绝不滞留正面主屏。
- **撤回直接销毁任务不闪现主屏**：点击「退出 / 撤回背屏桌宠」时直接 `removeTask` 清理，不再把窗口先搬回主屏停留。
- **修正竖屏背屏兜底 CSS**：解除 `.preview-shell` 的 `max-width: 100%` 限制，确保前端兜底分支同样全屏居中无偏移。
- **极简诊断日志（≤ 280 字）**：剔除冗余行并压缩格式，一条抖音私信/群聊即可装下 10+ 条完整关键状态轨迹。

### v1.0.7（修复 Android 17 背屏画面横倒 90° 问题）
- **双保险修复 Android 17 副屏方向异常**：抵达背屏后若系统以物理竖屏（`596×976`）承载画面，原生层自动请求横屏（不影响主屏方向），同时前端内置竖屏背屏 `-90°` 自动旋转与触摸坐标映射兜底，确保大眼睛、双摄避让和长按菜单全部正常摆正。

### v1.0.6（修复背面贴桌休眠触发 + 界面细节优化）
- **彻底修复「背面贴桌自动黑屏休眠」不生效问题**：改由背屏窗口直接监听连续硬件加速度计（`TYPE_ACCELEROMETER`）配合显式 5 秒定时器并放宽镜头凸起倾角容差，**无论是否开启守护模式**，正面朝上平放桌面 5 秒均可靠进入纯黑休眠省电，拿起或翻转立即亮回。
- **界面文案精简**：日志按钮恢复为简洁的「复制日志」（内部仍自动精简至 420 字以内，适配抖音/微信单条发送）。

### v1.0.5（实机投屏空白修复 + 精简日志 & 通知栏优化）
- **修复小米 17 Pro / 17 Pro Max 投屏后背屏空白问题**：移除页面加载完成时的误挂起逻辑并适配副屏 `STATE_ON_SUSPEND` 状态，确保每次投屏必先正常绘出大眼睛，仅在背屏明确熄灭（`STATE_OFF`）时才暂停渲染。
- **修复一键投屏首次偶发熔断重试**：移除 `am start` 无效参数，主屏暂存退后台提前至 `30ms`，并将搬运前 `onStop(d=0)` 解绑缓冲调整为 `820ms`（覆盖实机 ~600ms 系统动画耗时），兼顾一次成功与防主屏卡死安全。
- **诊断日志精简至 420 字以内**：点击「复制精简日志」自动生成一行设备状态头 + 最近关键事件缩写，方便在抖音 / 微信聊天窗口一条发完。
- **文案与界面打磨**：优化通知栏常驻文案（去掉开发术语，随贴桌省电开关动态变化）；移除无实际功能的「左右轻滑彩蛋」提示。

### v1.0.4（稳定性与省电细节再加固）
- **移除 WebView 内置重复屏幕常亮锁**：在原生 App 内交由安卓原生逻辑统一接管背屏常亮与休眠，避免 Chromium 底层 `navigator.wakeLock` 阻碍「背面贴桌休眠」彻底熄屏。
- **守护进程自愈机制**：若系统长时间休眠后回收了底层 Shizuku 常亮子进程，下次触发拉回指令时会自动静默重连，确保锁屏状态切回默认主题自动拉回长期稳定不失效。
- **固定子步长弹簧物理**：在 5 FPS / 14 FPS / 24 FPS / 30 FPS 自适应帧率下保持与 60 FPS 完全一致的丝滑回弹手感，杜绝低帧率抖动。
- **细节修复**：平放桌面时再次点击「一键投到妙享背屏」立即重置休眠计时；WebView 加载完成时自动同步当前背屏开关/休眠态；休眠与熄屏期间彻底停止时钟 DOM 刷新。

### v1.0.3（深度功耗优化 + 防主屏卡死硬熔断）
- **深度渲染省电（功耗显著下降）**：重构 Canvas 渲染管线，彻底移除高耗电 GPU `shadowBlur` 动态阴影改用轻量双层光晕；采用自适应帧率调度（待机 14 FPS / 互动 30 FPS / 瞌睡 5 FPS）并限制渲染像素比，让 LTPO 背屏自动降频，同时默认 OLED 亮度调优至 78%（可在背屏长按菜单自由调节）。
- **背屏熄屏零耗电 + 事件驱动守护**：监听背屏物理开关状态，背屏熄灭时立即暂停动画循环与后台轮询（0% GPU/CPU 占用）；背屏再次亮起瞬间毫秒级恢复，锁屏切回原主题照常自动拉回。
- **新增「背面贴桌自动黑屏休眠（省电推荐）」**：开启守护模式后，手机正面朝上平放桌面 6 秒自动纯黑休眠并释放背屏常亮锁，拿起或翻转手机立即唤醒并自动拉回大眼睛（无需解锁主屏，可在 App 首页随时开关）。
- **新增主屏防卡死硬熔断机制**：除主屏暂存期间禁止拦截触摸、主动退后台与强校验搬运外，新增 `onStop(d=0)` 生命周期硬熔断，物理杜绝背屏画面意外投到正面锁死屏幕。

## 关于双击背屏息屏的说明
- 若你在「守护模式」下双击背屏导致系统跳回原主题，新版 `v1.0.2` 会自动拉回桌宠（锁屏状态也会自动拉回）；
- 若系统双击背屏触发了小米自带的「双击息屏」，再次亮起背屏时同样会自动切回桌宠，如需彻底关闭双击息屏可在手机系统「设置 → 息屏与锁屏」中关闭「双击亮屏与息屏」。
